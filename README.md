# time-back-pages

Time Back プロジェクトの公開ドキュメント(プライバシーポリシー等)をホスティングするためのリポジトリです。

GitHub Pages で公開しています。

## 掲載ページ

- `index.html` — ドキュメントのハブページ
- `privacy-policy.html` — Shorts Limiter 拡張機能のプライバシーポリシー(日英併記)

## 公開URL

GitHub Pages 有効化後、以下のURLでアクセスできます:

- ハブ:`https://<ユーザー名>.github.io/time-back-pages/`
- ポリシー:`https://<ユーザー名>.github.io/time-back-pages/privacy-policy.html`

## 注意

このリポジトリは**公開**です。掲載するのは元々公開を前提とした文書(プライバシーポリシー等)のみで、開発中の拡張機能のソースコードは含めません。拡張機能の本体は別の非公開リポジトリ(`time-back`)で管理しています。
