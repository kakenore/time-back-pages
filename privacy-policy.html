Shorts Limiter

プライバシーポリシー

最終更新日:2026年5月17日(申請時に更新予定)

Shorts Limiter(以下「本拡張機能」)は、利用者の個人データを一切収集、送信、共有しません。 本拡張機能のすべての処理は、利用者のブラウザ内で完結します。

1. 収集する情報

本拡張機能は、外部に送信されるいかなる個人情報・利用データも収集しません。

本拡張機能は、機能の提供に必要な以下の情報を、利用者の端末内にのみ保存します。これらの情報が利用者の端末から外部に送信されることはありません。

  • 利用者が設定した制限値(1日のShorts視聴本数の上限、視聴時間の上限、その他の設定)
  • 当日のShorts視聴本数および視聴時間のカウンター(日付が変わるとリセットされます)
  • Strict Mode の有効状態およびロック期限

これらは Chrome の storage API を用いて端末内にローカル保存されます。

2. 情報の利用目的

保存された情報は、本拡張機能が利用者の端末内で機能を提供する目的(視聴回数・時間の計測、制限の実行、設定の保持)のためにのみ使用されます。他の目的には一切使用しません。

3. 情報の共有・第三者提供

本拡張機能は、利用者のいかなる情報も第三者と共有・提供・販売しません。本拡張機能は広告を表示せず、広告目的のデータ収集も行いません。

4. 権限について

本拡張機能は、機能の提供に必要な最小限の権限のみを要求します。

  • storage:利用者の設定とカウンターを端末内に保存するために使用します。
  • tabs:視聴の上限に達した際に、現在開いているタブの表示先を切り替えるために使用します。閲覧履歴の取得・記録には使用しません。
  • www.youtube.com へのアクセス:YouTube 上で Shorts ページを検知し、残り時間のオーバーレイを表示するために使用します。

5. データの保存とセキュリティ

すべてのデータは利用者の端末内にのみ保存されます。本拡張機能は外部サーバーと通信を行わないため、データが端末外に送信されることはありません。

6. データの削除

本拡張機能をブラウザからアンインストールすると、保存されたすべてのローカルデータが削除されます。また、ブラウザの拡張機能管理画面から本拡張機能のデータを消去することもできます。

Privacy Policy

Last updated: May 17, 2026 (to be updated upon submission)

Shorts Limiter ("the extension") does not collect, transmit, or share any personal user data. All processing happens locally within the user's browser.

1. Information We Collect

The extension does not collect any personal or usage data that is sent outside the user's device.

The extension stores the following information solely on the user's device. This information never leaves the device:

  • User-defined limits (daily Shorts view count limit, watch-time limit, and other settings)
  • The current day's Shorts view count and watch-time counters (reset when the date changes)
  • Strict Mode status and lock expiry

This data is stored locally using Chrome's storage API.

2. How We Use Information

Stored information is used only to provide the extension's functionality on the user's device (counting views and time, enforcing limits, retaining settings). It is not used for any other purpose.

3. Data Sharing

The extension does not share, sell, or transfer any user information to third parties. The extension shows no advertising and performs no data collection for advertising purposes.

4. Permissions

  • storage: to save user settings and counters on the device.
  • tabs: to change the destination of the current tab when a viewing limit is reached. It is not used to read or record browsing history.
  • Access to www.youtube.com: to detect Shorts pages and display the remaining-time overlay.

5. Data Storage and Security

All data is stored only on the user's device. The extension does not communicate with any external server, so no data is transmitted off the device.

6. Data Deletion

Uninstalling the extension removes all stored local data. Users can also clear the extension's data from the browser's extension management page.
